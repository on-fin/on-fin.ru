## Новое название – Финдикатор

Система называется **Финдикатор**, сайт – [findikator.ru](https://findikator.ru). В некоторых местах таблицы ещё встречается прежнее название «ФинУчет» – оно постепенно уйдёт.

## Окно Финдикатора

Вся работа – в одном окне поверх таблицы: **Финансы → Открыть Финдикатор**. Разделы: Сегодня, Дашборд, Загрузка, Разноска, Операции, Отчёты, Бюджет, Платёжный календарь, Настройка. См. [Обзор окна](nachalo/obzor-okna).

- **Загрузка из 1С перетаскиванием файла**, несколько карточек сразу.
- **Загрузка операций из Excel по шаблону** – для кассы вне 1С и переноса учёта из Excel. См. [Загрузка операций из Excel](zagruzka-1c/iz-excel).
- **Операции:** поиск, отбор, правка статьи и даты начисления прямо в списке, назначение статьи нескольким операциям.
- **Окно операции:** создание правила одной галочкой, разбиение суммы, распределение на период.
- **Отчёты** за любой период по месяцам или кварталам, с расшифровкой каждой суммы.
- **Подсказки «?»** у кнопок.

## Предпросмотр загрузки

Новые операции можно посмотреть и поправить **до** записи в таблицу. См. [Предпросмотр](zagruzka-1c/predprosmotr).

## Ручные операции

**«Оплачено»** и **«Ждём оплату»** – для того, чего нет в 1С. Связывание оплат из 1С с ручными начислениями. См. [Ручные операции](operacii/ruchnye).

## Бюджет доходов и расходов (БДР)

Кроме БДДС теперь есть БДР – план по строкам ОПУ и план-факт с комментариями. См. [БДР и БДДС](byudzhet/bdr-bdds).
